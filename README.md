# dam-psp

**Español** | [English](#english)

Programación de servicios y procesos del ciclo de DAM: clientes de correo (SMTP) y de transferencia de ficheros (FTP) en Java.

| Carpeta | Qué es | Periodo |
|---|---|---|
| [`SMTP_Entrega_PSP`](SMTP_Entrega_PSP/) | Entrega de la asignatura de PSP (Programación de Servicios y Procesos) del ciclo de DAM, abril de 2023. Pequeño programa en Java que envía un correo de prueba a través del servidor SMTP de Gmail con JavaMail. | 2023-04 |
| [`FTP_Entrega_PSP`](FTP_Entrega_PSP/) | Entrega de la asignatura de PSP (Programación de Servicios y Procesos) del ciclo de DAM, abril de 2023. Cliente FTP en Java por consola, con un menú, hecho con Apache Commons Net. | 2023-04 |

Cada carpeta conserva su propio README, licencia y `.gitignore`. El historial de commits de cada proyecto original está incluido en este repositorio.

## English

Services and processes programming from my DAM course: Java clients for mail (SMTP) and file transfer (FTP).

| Folder | What it is | Period |
|---|---|---|
| [`SMTP_Entrega_PSP`](SMTP_Entrega_PSP/) | Assignment for the PSP (Services and Processes Programming) subject of my DAM vocational course, April 2023. A small Java program that sends a test email through Gmail's SMTP server using JavaMail. | 2023-04 |
| [`FTP_Entrega_PSP`](FTP_Entrega_PSP/) | Assignment for the PSP (Services and Processes Programming) subject of my DAM vocational course, April 2023. A console FTP client in Java with a menu, built with Apache Commons Net. | 2023-04 |

Each folder keeps its own README, license and `.gitignore`. The commit history of every original project is included in this repository.
